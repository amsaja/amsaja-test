# 김슬기 공식 아카이브 v2.0

방향
- 설명을 줄이고 콘텐츠가 말하게 하는 편집 디자인
- 장기적으로 계속 쌓아갈 수 있는 작가 아카이브 구조

페이지 순서
ABOUT → WORKS → COLUMN → TALKS → HISTORY → PRESS → CONTACT

주요 변경
- About 첫 화면을 조용한 브랜드 히어로로 정리
- 대표 활동 카드 대신 현재 아카이브 수량 표시
- 각 큰 카테고리 하단 설명 삭제
- Talks 사진 우선 배치 + 기관 유형별 분류 유지
- History 4갈래(출간·발표 / 수상·선정 / 해외·번역 / 연재·활동) 유지
- Press는 하단의 부록 같은 위치로 정리
- Contact를 Email / Instagram / Blog 세 줄로 단순화
- Footer에 `Archive is continuously updated.`와 Last updated 표시
- 모바일 플로팅 바 수정 유지
