# 김슬기 홈페이지 — refined single-page edition

이번 버전은 사용자가 직접 수정한 index.html을 기준으로 재구성했습니다.

변경 사항
- 상단 픽셀 배너 제거: 게임 콘셉트는 플로팅 캐릭터/우주와 섹션 아이콘에 집중
- About에 실제 작가 사진을 작게 추가
- 기사·인터뷰: 기존 외부 기록 10건을 모두 복원, 한 화면에 5개씩 페이지 이동
- CEO저널 링크 최신 주소 반영
- 강연·수업: 기존 주요 5개 요약 대신 기관·프로그램별 상세 아카이브로 확장
- 모바일 레이아웃 및 키보드 포커스 보강
- 내부 파일 경로, 앵커, 중복 id 점검 완료
