# 김슬기 공식 홈페이지 — 공개용 최종판

이 버전은 현재 제공된 이력서, 작품 정보, 사진, 책 표지와 기존 홈페이지 아카이브만으로 구성했습니다.

## 주요 파일
- index.html — 메인 / 소개 / 연락처
- works.html — 작품
- talks.html — 강연과 워크숍
- archive.html — 활동 아카이브
- data/archive.json — 아카이브 데이터
- assets/style.css — 디자인
- assets/images/ — 사진과 표지
- robots.txt / sitemap.xml — 검색엔진용
- 404.html — 오류 페이지
