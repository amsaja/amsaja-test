# 김슬기 싱글페이지 픽셀 홈페이지

## 이번 버전
- 메인 픽셀 이미지는 장식용으로 단순화
- 이미지 아래에 작가 소개 배치
- 메인 페이지 하나에서 WORKS → COLUMN → PRESS → TALKS → HISTORY → CONTACT 순서로 계속 읽는 구조
- 플로팅 내비게이션이 화면을 따라다니며 같은 페이지의 각 섹션으로 이동
- 플로팅 메뉴에 복싱 캐릭터와 흰색 말티푸 우주 마스코트 배치
- 기존 works.html / talks.html / archive.html은 상세/백업 페이지로 그대로 유지
- 모바일에서는 하단 플로팅 메뉴로 전환
